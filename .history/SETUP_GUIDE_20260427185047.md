# Setup & Troubleshooting Guide

## 🔑 Getting Your GEMINI_API_KEY

1. Go to [https://ai.google.dev](https://ai.google.dev)
2. Click "Get API Key" button
3. Create a new project or use existing
4. Copy the API key

## ✅ Running the Pipeline

### Option 1: Set Environment Variable (Recommended)

**PowerShell:**
```powershell
$env:GEMINI_API_KEY = "your-api-key-here"
docker-compose up --build
```

**Bash/Linux:**
```bash
export GEMINI_API_KEY="your-api-key-here"
docker-compose up --build
```

**CMD (Windows):**
```cmd
set GEMINI_API_KEY=your-api-key-here
docker-compose up --build
```

### Option 2: Create .env File

Create a `.env` file in the project root:
```
GEMINI_API_KEY=your-api-key-here
```

Then run:
```bash
docker-compose up --build
```

## 🐛 Common Issues & Fixes

### Issue 1: "No API_KEY or ADC found"
**Cause:** GEMINI_API_KEY environment variable not set  
**Fix:** Follow "Running the Pipeline" section above

### Issue 2: "agent_prioritizer exited with code 1"
**Cause:** Summarizer failed, so summary.txt wasn't created  
**Fix:** Check summarizer logs - usually missing API key

### Issue 3: "Rate limit exceeded"
**Cause:** Too many API calls in short time  
**Fix:** Wait a moment, then retry. Code has retry logic with exponential backoff.

### Issue 4: "FileNotFoundError: '/data/prioritized.txt'"
**Cause:** Previous agents failed  
**Fix:** Check Docker logs for earlier failures:
```bash
docker-compose logs agent_summarizer
docker-compose logs agent_prioritizer
```

## 📝 Checking Logs

```bash
# All containers
docker-compose logs

# Specific container
docker-compose logs agent_summarizer
docker-compose logs agent_prioritizer
docker-compose logs agent_formatter

# Follow logs in real-time
docker-compose logs -f

# Clear logs
docker system prune
```

## 🧹 Clean Up

```bash
# Stop all containers
docker-compose down

# Remove all containers, images, volumes
docker-compose down -v

# Remove only stopped containers
docker container prune
```
